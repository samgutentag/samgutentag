# Sam Gutentag

Voice AI advocate, DevRel at Deepgram. I help developers build software you can
talk with, then build a map or wire up a sensor when I should probably be sleeping.

Most of what I make lives at [gutentag.world](https://www.gutentag.world). The
how-and-why ends up on [the blog](https://www.gutentag.world/blog).

### What I'm building

- **Voice AI experiments.** Small, real things that listen and talk: speech-to-text,
  text-to-speech, and voice agents. The day job, but it would be the hobby anyway.
- **Agentic dev tooling.** Multi-agent workflows, Claude Code skills, and MCP servers
  that do real work instead of demos.
- **Interactive maps.** Santa Barbara [BCycle stations](https://bcycle.gutentag.world)
  live off the GBFS feed, plus the food-week maps
  ([sandwich](http://sbsandwichweekmap.com), [coffee](https://sbcoffeeweekmap.com),
  [burger](https://sbburgerweekmap.com)) all running off one config-driven template.
- **Home and hardware.** A Raspberry Pi fleet, Home Assistant, Zigbee, and a corded
  landline that reads my kid a weather report.

### What I care about

Documentation as a first-class artifact, voice as a real interface instead of a
gimmick, and tools that earn their keep. Mostly I care whether the thing actually
works when someone else tries it.
